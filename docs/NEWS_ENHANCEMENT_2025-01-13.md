## ✨ 新增功能

### 1. 个股新闻详情弹窗 (NewsDetailModal)

**功能描述：**
- 点击扫描结果中的📰图标，查看该股票的相关新闻
- 自动从东方财富抓取最新新闻
- 支持手动刷新新闻
- 显示新闻来源、发布时间、标题
- 可直接跳转到原文链接

**组件位置：**
- `frontend/src/components/NewsDetailModal.tsx`

**API 端点：**
- `GET /api/news/stock/{code}` - 获取个股新闻
- `POST /api/news/refresh/{code}` - 刷新新闻缓存

**使用方法：**
1. 在扫描结果表格中，点击"新闻"按钮（📰图标）
2. 弹窗显示该股票的相关新闻列表
3. 点击"刷新新闻"按钮可立即抓取最新新闻
4. 点击新闻标题旁的外链图标查看原文

---

### 2. 风险预警通知 (RiskAlert)

**功能描述：**
- 实时监控市场风险事件
- 按风险等级分类（高/中/低）
- 按风险类型分类（财务/经营/市场/重大）
- 可忽略单条风险通知
- 可展开/收起详情

**组件位置：**
- `frontend/src/components/RiskAlert.tsx`

**API 端点：**
- `GET /api/news/risks?days=7` - 获取最近N天的风险事件

**风险等级说明：**
- 🔴 **高风险** (High): 立案调查、财务造假等严重事件
- 🟡 **中风险** (Medium): 减持、行政处罚、市场风险
- ⚪ **低风险** (Low): 一般性风险提示

**风险类型说明：**
- **财务** (Financial): 业绩下滑、亏损、债务问题
- **经营** (Operational): 立案调查、处罚、诉讼
- **市场** (Market): 减持、质押、解禁
- **重大** (Major): 事故、停产、重大人事变动

## 🎨 UI/UX 设计

### 色彩系统
- **热点题材**：橙色系（🔥 火焰图标）
- **风险预警**：红色系（⚠️ 警告图标）
- **新闻按钮**：橙色调，悬停时变为橙色背景
- **生命周期阶段**：
  - 爆发期：红色
  - 成长期：橙色
  - 成熟期：黄色
  - 衰退期：灰色

### 动画效果
- 风险预警徽章：脉冲动画（animate-pulse）
- 展开详情：淡入下滑动画（fade-in slide-in-from-top）
- 按钮：缩放和颜色过渡动画

## 🔧 技术实现

### 前端技术栈
- React Hooks (useState, useEffect)
- Lucide React 图标库
- Tailwind CSS 样式
- Axios HTTP 客户端

### 后端技术栈
- FastAPI
- SQLAlchemy
- PostgreSQL
- BeautifulSoup4 (网页爬虫)
- scikit-learn (TF-IDF 去重)

### 数据流程
1. **新闻抓取**：EastMoneyCrawler → 去重 → 缓存
2. **题材追踪**：统计新闻 → 计算热度 → 更新数据库
3. **风险检测**：关键词匹配 → 等级判断 → 存储事件
4. **前端展示**：API 请求 → 渲染组件 → 用户交互

## 📝 使用指南

### 查看个股新闻
1. 启动全市场扫描
2. 在扫描结果中找到感兴趣的股票
3. 点击该股票行的"新闻"按钮（📰图标）
4. 查看相关新闻，可点击"刷新新闻"获取最新数据

### 查看风险预警
1. 风险预警横幅会自动显示在首页
2. 显示最近7天的高/中风险事件
3. 点击"查看详情"展开所有风险事件
4. 可点击"忽略"按钮隐藏单条通知

### 刷新热点题材
- 热点题材每小时自动更新
- 也可通过API手动触发更新
