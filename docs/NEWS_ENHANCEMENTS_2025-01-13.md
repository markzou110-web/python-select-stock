## ✨ 新增功能概览

### 1. AI 情绪分析可视化 📊

**功能描述：**
在新闻详情弹窗中显示情绪分析图表，帮助用户快速了解新闻舆情倾向。

**显示内容：**
- 情绪评分 (-5 到 +5)
- 情绪趋势指标 (看涨/看跌/中性)
- 正面/负面/中性新闻统计
- 进度条可视化

**颜色编码：**
- 🟢 绿色：正面情绪 (评分 > 2)
- ⚪ 灰色：中性情绪 (-2 ≤ 评分 ≤ 2)
- 🔴 红色：负面情绪 (评分 < -2)

**使用方法：**
1. 在扫描结果中点击 📰 新闻按钮
2. 查看弹窗顶部的"情绪分析"卡片
3. 评分条显示情绪倾向
4. 统计卡片显示各类新闻数量

---

### 2. 题材成分股列表 📋

**功能描述：**
点击题材卡片查看该题材的相关股票列表，包括涨跌幅、成交额等数据。

**功能特点：**
- 显示题材相关股票及代码
- 实时价格和涨跌幅
- 成交额统计
- 相关度评分（0-100%）
- 三种排序方式：相关度/涨跌幅/成交额

**交互方式：**
- 点击题材卡片打开成分股弹窗
- 点击排序按钮切换排序方式
- 点击股票行跳转到东方财富详情

**数据字段：**
| 字段 | 说明 | 示例 |
|------|------|------|
| 股票 | 名称和代码 | 宁德时代 300750 |
| 现价 | 当前价格 | ¥185.50 |
| 涨跌幅 | 当日涨跌幅 | +3.2% |
| 成交额 | 当日成交额 | 15.00 亿 |
| 相关度 | 与题材关联程度 | 95% |

---

### 3. 新闻推送通知 🔔

**功能描述：**
实时推送重要新闻、风险事件和题材异动通知到浏览器。

**通知类型：**

1. **风险预警** (⚠️)
   - 检测到高风险事件时推送
   - 例如：某股票被立案调查

2. **题材异动** (🔥)
   - 题材热度大幅上升时推送
   - 例如：人工智能热度突破 200

3. **新闻快讯** (📰)
   - 重要市场新闻推送
   - 例如：央行宣布降准

**功能特点：**
- 浏览器通知支持（需授权）
- 未读数量徽章提示
- 通知中心面板
- 全部已读功能
- 时间倒序显示

**通知权限：**
- 首次使用会请求通知权限
- 可在浏览器设置中更改
- 权限状态显示在通知中心底部

```
新闻列表
  ↓
调用 DeepSeek API
  ↓
计算情绪评分 (-5 到 +5)
  ↓
分类：正面/负面/中性
  ↓
统计各类数量
  ↓
可视化展示
```

### 题材成分股流程
```
点击题材
  ↓
查询题材相关股票
  ↓
获取实时行情数据
  ↓
计算相关度
  ↓
排序显示
```

```
定时轮询 (每分钟)
  ↓
获取新通知
  ↓

  ↓
发送浏览器通知
  ↓
更新通知中心
```

## 💡 使用场景

### 场景 1：查看个股舆情

**操作步骤：**
1. 运行市场扫描
2. 在结果中找到感兴趣股票
3. 点击 📰 新闻按钮
4. 查看情绪分析卡片
5. 阅读相关新闻

**获得信息：**
- 新闻情绪倾向（正面/负面）
- 情绪评分和趋势
- 正负面新闻占比
- 相关新闻列表

### 场景 2：研究题材成分股

**操作步骤：**
1. 在首页查看热点题材
2. 点击感兴趣的题材卡片
3. 在成分股列表中排序
4. 查看个股涨跌和相关度
5. 点击股票查看详情

**获得信息：**
- 题材包含的股票
- 各股票实时表现
- 成交额和活跃度
- 与题材的关联度

### 场景 3：接收重要通知

**操作步骤：**
1. 允许浏览器通知权限
2. 系统自动检测重要事件
3. 浏览器推送通知
4. 点击通知中心铃铛图标
5. 查看所有通知详情

**接收通知：**
- 风险预警事件
- 题材热度异动
- 重要市场新闻

## 📝 配置说明

### 通知轮询间隔

当前设置为每分钟轮询一次：
```typescript
const interval = setInterval(() => {
    checkNewNotifications();
}, 60000); // 60秒
```

可在 `NewsNotification.tsx` 中修改。

### 情绪分析阈值

当前阈值设置：
```typescript
sentiment.average_score > 2  // 正面
sentiment.average_score < -2  // 负面
// 其他为中性
```

可在 `SentimentAnalysis.tsx` 中调整。
