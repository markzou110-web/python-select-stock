# 价格行为路径质量研究（2026-08-20）

## 假设

在现有 TV 或均线信号与 `PA >= 60` 门禁之后，剔除以下两类候选，可能减少追高失败：

1. 近 20 个交易日的上涨主要由少数交易日贡献（`DISCRETE_JUMP`）。
2. 20 日涨幅、波动调整后的趋势强度、以及价格相对 EMA20 的 ATR 乖离同时进入极端区间（`pa_extreme_trend`）。

依据：

- [Empirical determinants of momentum: a perspective using international data](https://academic.oup.com/rof/article/29/1/241/7772889)：动量在上涨、低波动市场更强，渐进的信息扩散路径具有较稳定的解释力。
- [Nonlinear Time Series Momentum](https://papers.ssrn.com/sol3/Delivery.cfm/5933974.pdf?abstractid=5933974&mirid=1)：趋势强度与后续风险调整收益并非简单线性关系。该文为工作论文，因此这里只将其用于提出影子候选，不直接改生产策略。

## 回放协议

- 股票范围：本地全市场 5,286 只股票。
- 数据区间：2022-05-12 至 2026-08-20，共 130,491 个 TV（均线或 ZP）历史事件。
- 时间切分：训练至 2024-12-31；验证为 2025 年；测试为 2026 年至回放日。
- 基线：`PA >= 60` 且价格行为建议不是 `AVOID`。
- 候选：基线基础上排除 `DISCRETE_JUMP` 和 `pa_extreme_trend`。
- 执行：T 日收盘确认，T+1 按确认价/开盘约束成交；5bp 滑点、A股双边费用、-9% 止损；均线按 +15% 或 EMA20 破位次日开盘退出，ZP 按 short 次日开盘退出。
- 同一股票持仓期间忽略同门禁的重复买点；日线无法识别盘中先后顺序时采用止损优先。

复现命令：

```bash
cd backend
venv_new/bin/python -m core.a_grade_kline_replay --skip-research-protocol
```

## 决策

候选门禁在验证段改善明显，测试段也降低了止损率并缩小平均亏损，但测试胜率下降 0.35 个百分点，平均收益仍为负，盈亏因子仍小于 1。因此结论为 `NO_SUPPORTED_GATE`：

- 不改变当前价格行为评分、READY/WATCH、买卖点或 Bark 文案。
- 只持久化路径质量、信息离散度、趋势效率、头部交易日贡献、非线性强度、EMA20 ATR 乖离等影子字段。
- 继续收集新的前向样本；只有在新的、未参与本次研究的数据上同时改善胜率、平均收益、盈亏因子与回撤后，才考虑启用。

## 限制

- 本地 `daily_k` 为前复权价格，未来公司行动可能回写历史价格；历史成交价、手数和最低佣金均为近似，不能视为完全点时回测。
- 当前股票名称和行业来自现时 `stock_basic`，存在存活与分类变化偏差。
- 尚未进行组合层资金占用、并发持仓和最大回撤比较。
- 2026 测试段包含尚未产生策略卖点的未成熟持仓；这些持仓不计入完成交易收益。
