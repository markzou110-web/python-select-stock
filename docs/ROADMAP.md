## 未来版本: v7.0

**预计发布**: 2025 Q3 (7-9月)
**优先级**: 中

### 核心主题: 智能化与自动化

#### 1. 实时预警系统 🔥
**优先级**: P0
**工作量**: 3-4周

**功能描述**:
- 价格突破EMA20时自动预警
- 成交量异常放大预警
- RSI 超买/超卖预警

**预警渠道**:
- [ ] 邮件通知 (SMTP)
- [ ] Webhook (钉钉/企微/飞书)
- [ ] 浏览器推送 (Web Push API)
- [ ] 移动端推送 (未来)


---

#### 3. 机器学习增强 (实验性) 🧪
**优先级**: P2
**工作量**: 6-8周

**探索方向**:
- 使用历史数据训练分类模型
- 特征工程: 技术指标 + 市场环境
- 目标: 预测信号未来5日涨幅 > 3% 的概率

**技术方案**:
- scikit-learn / XGBoost
- 特征: RSI, MACD, BB Width, 涨跌幅, 量比, 换手率, PE, 板块强度
- 标签: 历史信号是否成功 (5日内涨幅 > 3%)

**输出**:
```
扫描结果新增列:
- ML预测概率: 78%
- ML建议: ⭐⭐⭐⭐ (4星)
```

**风险提示**:
- ML 仅作为辅助参考
- 不保证未来表现
- 需持续监控模型效果
