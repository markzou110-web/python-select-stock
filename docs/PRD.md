# Alpha Vision - 产品需求文档 (PRD)

**版本**: v6.0
**最后更新**: 2025-01-12
**产品类型**: A股量化选股与交易辅助终端
**技术架构**: Python FastAPI + Next.js + PostgreSQL

---

## 1. 产品概述

### 1.1 产品定位
Alpha Vision 是一款面向 A股个人投资者的**本地化量化选股工具**，通过"均线粘合 + 趋势突破"策略自动筛选市场机会，提供历史回测、模拟交易等辅助决策功能。

### 1.2 目标用户
- **主要用户**: 有一定技术基础的 A股个人投资者
- **次要用户**: 量化策略研究者、交易员
- **非目标用户**: 纯技术分析用户（需图表工具）、机构投资者（需高并发）

### 1.3 核心价值主张
- **本地化部署**: 完全掌控数据，无API费用
- **策略透明**: 所有指标逻辑可审查、可定制
- **快速扫描**: 5秒内完成全市场5000+标的筛选
- **数据自主**: 本地PostgreSQL存储，离线可用

### 1.4 与竞品差异化
| 特性 | Alpha Vision | 同花顺/东方财富 | TradingView |
|------|--------------|----------------|-------------|
| 部署方式 | 本地化 | SaaS | SaaS |
| 策略定制 | 完全开放 | 封闭 | Pine Script |
| 数据费用 | 免费(akshare) | 免费 | 付费 |
| A股支持 | 原生 | 原生 | 有限 |
| 回测功能 | 有 | 有 | 有 |

## 2. 功能需求

### 2.1 核心功能 (P0 - 必须实现)

#### 2.1.1 市场数据同步
**功能描述**: 自动从 akshare 获取 A股历史行情和实时数据

**用户故事**:
> 作为投资者，我希望系统每天自动更新股票数据，这样我就能基于最新数据做决策

**验收标准**:
- [ ] 支持增量同步（仅同步新增交易日数据）
- [ ] 支持手动触发全量同步
- [ ] 并发下载优化（10个工作线程）
- [ ] 同步进度实时展示（百分比、成功/失败数）
- [ ] 仅同步市值≥50亿股票（可配置）
- [ ] 数据包含：开高低收、成交量、技术指标
- [ ] 异常处理：网络超时、API限流自动重试

**技术实现**:
- 文件: `backend/sync_data.py`
- API: `POST /api/sync/daily`
- 存储: PostgreSQL `daily_k` 表

---

#### 2.1.2 多因子策略扫描
**功能描述**: 基于"均线粘合 + 趋势突破"策略扫描市场机会

**用户故事**:
> 作为投资者，我希望系统能自动筛选符合"均线粘合后放量突破"的股票，这样我就不需要手动翻看5000只股票

**验收标准**:
- [ ] 支持全市场扫描（剔除ST、退市、北交所）
- [ ] 策略参数可调：
  - 粘合度阈值 (默认 8-12%)
  - 量比倍数 (默认 1.5-2.0)
  - RSI最小值 (默认 55)
  - MACD过滤开关
  - 周线趋势过滤开关
  - 布林带收缩过滤
- [ ] 扫描结果按评分排序（Top 30）
- [ ] 显示关键指标：
  - 股票代码/名称
  - 现价、涨跌幅
  - 量比、换手率、PE
  - RSI、MACD、粘合度
  - 所属行业
  - 历史胜率

**技术实现**:
- 文件: `backend/core/strategy.py::check_strategy()`
- API: `GET /api/scan`
- 前端: `frontend/src/components/ResultsTable.tsx`

---

## 3. 非功能性需求

### 3.1 性能要求
| 指标 | 目标值 | 测量方法 |
|------|--------|----------|
| 市场扫描响应时间 | < 10秒 | 从点击扫描到结果展示 |
| 数据同步速度 | > 100只/分钟 | 并发10线程 |
| 页面首次加载 | < 3秒 | Network面板 |
| 历史回测计算 | < 2秒 | 单只股票1年数据 |
| 数据库查询 | < 500ms | 索引优化后 |

### 3.2 可用性要求
- **系统可用性**: 99% (交易日 9:00-15:00)
- **数据准确性**: 99.9% (与 akshare 源数据一致)
- **并发用户**: 1-5人 (个人/小团队使用)
- **故障恢复**: 自动重试机制，最多3次

### 3.3 数据要求
| 项目 | 说明 |
|------|------|
| 数据源 | akshare (免费API) |
| 更新频率 | 盘后自动同步 + 盘中可选 |
| 数据延迟 | T-1 (免费数据限制) |
| 存储周期 | 保留全部历史数据 |
| 数据容量 | 约 5000只股票 × 365天 × 10列 ≈ 200MB/年 |

### 3.4 安全要求
- 本地部署，无外网暴露
- 数据库密码本地存储（`db_config.json`）
- 无用户认证系统（单机使用）
- API不暴露敏感信息

### 3.5 兼容性要求
| 环境 | 要求 |
|------|------|
| 操作系统 | macOS, Linux, Windows |
| Python | 3.9+ |
| Node.js | 18+ |
| PostgreSQL | 12+ |
| 浏览器 | Chrome, Firefox, Safari (最新版) |

### 3.6 可维护性要求
- 代码结构模块化（core/, components/）
- 关键函数添加文档字符串
- 错误日志记录到控制台
- 数据库迁移脚本 (`init_db()`)

## 4. 数据模型

### 4.1 核心数据表

#### stock_basic (股票基础信息)
```sql
CREATE TABLE stock_basic (
    code VARCHAR(20) PRIMARY KEY,
    name VARCHAR(100),
    industry VARCHAR(50),
    market_cap BIGINT,
    list_date DATE
);
```

#### daily_k (日线数据)
```sql
CREATE TABLE daily_k (
    code VARCHAR(20),
    date DATE,
    open FLOAT,
    high FLOAT,
    low FLOAT,
    close FLOAT,
    volume BIGINT,
    amount FLOAT,
    -- 技术指标
    ema5 FLOAT, ema10 FLOAT, ema20 FLOAT, ema60 FLOAT,
    rsi FLOAT,
    macd_dif FLOAT, macd_dea FLOAT, macd_bar FLOAT,
    bb_upper FLOAT, bb_lower FLOAT, bb_width FLOAT,
    vol_ma20 FLOAT,
    PRIMARY KEY (code, date)
);
```

#### scan_history (扫描历史)
```sql
CREATE TABLE scan_history (
    id SERIAL PRIMARY KEY,
    code VARCHAR(20),
    date DATE,
    score FLOAT,
    close_price FLOAT,
    change_pct FLOAT,
    volume_ratio FLOAT,
    rsi FLOAT,
    macd_dif FLOAT,
    bb_width FLOAT,
    squeeze_ratio FLOAT,
    sector VARCHAR(50),
    historical_win_rate FLOAT,
    signal_count INTEGER,
    created_at TIMESTAMP DEFAULT NOW()
);
```

#### paper_trading (模拟交易)
```sql
CREATE TABLE paper_trading (
    id SERIAL PRIMARY KEY,
    code VARCHAR(20),
    name VARCHAR(100),
    buy_price FLOAT,
    buy_date DATE,
    quantity INTEGER,
    created_at TIMESTAMP DEFAULT NOW()
);
```

## 7. 风险与限制

### 7.1 技术风险
| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| akshare API限流 | 数据同步失败 | 请求限流、重试机制 |
| PostgreSQL数据损坏 | 数据丢失 | 定期备份 |
| 网络不稳定 | 同步中断 | 增量同步、断点续传 |

### 7.2 业务风险
| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 策略失效 | 亏损 | 历史回测验证 |
| 数据延迟 | 错过机会 | 明确T+1限制 |
| 过度依赖工具 | 缺乏判断 | 风险提示、投资教育 |

### 7.3 产品限制
- **数据延迟**: 使用免费数据源，T+1延迟
- **非实时**: 盘中数据需要手动刷新
- **单机使用**: 不支持多用户协作
- **A股专用**: 不支持港股、美股

- **EMA**: 指数移动平均线

- **MACD**: 平滑异同移动平均线
- **量比**: 当前成交量 / 过去20日平均成交量
- **粘合度**: (MA最高 - MA最低) / MA最低
