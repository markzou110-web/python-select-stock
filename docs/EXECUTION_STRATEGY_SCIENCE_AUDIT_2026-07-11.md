# 股票执行策略科学性审计与验证规范

日期：2026-07-11  
范围：股票已经被选出之后，判断是否允许买入及如何控制仓位。本文不调整选股逻辑。

## 1. 核心原则

系统必须区分“发现股票”和“允许交易”。股票进入扫描结果、获得A级或出现强势异动，都不自动等于可以买入。Bark 只有在以下两个字段同时成立时才能显示 `指令：可交易`：

```text
trade_bucket = TRADE
trade_eligible = true
```

其他任何状态统一显示 `指令：不可交易`。用户仍需按确认价、仓位上限和失效价执行。

## 2. 当前执行链

1. 价格行为生成确认价、止损价、目标价和回踩状态。
2. SOP 执行层检查策略类型、评级、板块联动、量能、收盘稳定性、涨停追高和结构风险。
3. 决策层计算市场、板块、龙头地位、技术、资金和风险组成的综合机会分。
4. 市场退潮、板块退潮、机会分低于生产阈值时降为观察。
5. 策略健康度使用成熟的未来5日样本决定 ACTIVE、DOWNWEIGHT 或 PAUSED。
6. 官方重大催化股票可以在首次健康回踩完全确认后进入2%～3%的事件试仓。
7. Bark 使用双门禁输出最终可交易或不可交易指令。

## 3. 阻断原因审计分类

现有生产准入暂不改变；新增分类用于证明每类门禁是否有效。

### 3.1 硬禁止（hard）

- 价格行为回避或结构失效；
- 冲高回落、涨停或近涨停、高开追价；
- 异常价格、板块明确下跌；
- 关键点时数据不完整或仅供研究；
- 其他明确标记为禁止实盘的风险。

### 3.2 等待确认（wait）

- 未站上或未站稳确认价；
- 量能未确认；
- 尚未完成回踩或次日确认；
- 换手不足、交易计划未确认。

### 3.3 软性环境（soft）

- 市场或板块退潮；
- 板块强度不足、降级观察；
- 策略近期负期望；
- 综合机会分低于60；
- 资金流偏弱、原始分偏低、周线环境中性。

### 3.4 未分类（other）

新出现且尚未建立统计依据的原因进入 other。不得自动当作可豁免条件。

扫描结果新增 `trade_blocker_groups`，只增加审计字段，不改变选股和现有交易准入。

## 4. 仓位风险归一化

机会分仍决定基础仓位档位，但实际仓位增加止损距离封顶：

```text
最大仓位比例 = 单笔组合风险预算 ÷ 结构止损距离
```

当前单笔组合风险预算为总资金的1%。例如：

| 结构止损距离 | 风险封顶仓位 |
|---:|---:|
| 5% | 20% |
| 8% | 12.5% |
| 10% | 10% |
| 16% | 6.25% |

最终仓位取“机会分仓位、市场总仓上限、止损距离风险仓位”三者的最小值。缺少有效止损距离时不静默扩大或缩小原仓位，但通过 `stop_risk_pct=null` 暴露数据缺口。

输出字段：

- `risk_budget_pct`：单笔组合风险预算；
- `stop_risk_pct`：结构止损距离；
- `max_position_by_risk_pct`：风险预算允许的最大仓位；
- `estimated_initial_risk_pct`：初始仓位预计组合风险；
- `risk_capped`：是否发生风险封顶。

## 5. 三组绩效归因

新增只读接口：

```text
GET /api/review/execution-science-report?days=120
```

必须在相同的信号日收盘和未来交易日收益口径下比较：

1. `research_candidate`：所有可研究候选；
2. `blocked_candidate`：可研究但被执行门禁拦截；
3. `executable_candidate`：同时满足 TRADE 和 trade_eligible 的 Bark 可交易候选。

主要观察未来5日：样本数、胜率、平均收益、中位数收益、盈亏因子、最好与最差收益。同时保留1、3、10日用于判断买点效率和持有延展。

判断规则：

- 可交易组持续优于被拦截组，说明门禁具有筛选价值；
- 被拦截组显著优于可交易组，说明门禁可能过严或分类错误；
- 两组样本不足时不得修改生产规则；
- 相关性结果不直接解释为因果，必须进行滚动样本外验证。

## 6. 机会分阈值敏感性

生产阈值继续保持60，不自动调整。报告并行计算55、60、65、70四档：

- 入选样本数；
- 未来5日胜率；
- 平均和中位收益；
- 盈亏因子；
- 最差收益。

只有在多个滚动窗口中出现稳定的样本外优势，才允许提出阈值变更。禁止根据单只股票或单个时间窗口调参。

## 7. 策略健康度解释边界

当前健康度主要基于 `research_eligible=true` 的成熟候选，评估的是候选质量，不完全等同于真实可执行信号收益。后续报告必须同时展示研究候选、Bark推荐事件和真实交易三层，不得混用胜率。

暂停策略的依据应包括：

- 至少20个成熟样本；
- 期望收益为负；
- 置信区间或负期望幅度达到暂停条件；
- 明确记录样本范围、市场阶段和策略版本。

事件驱动股票的普通策略健康度只作为影子参考，不绕过价格硬风险。

## 8. 强势事件股执行规则

强势异动本身不可交易。只有同时满足以下条件才进入事件试仓：

- 官方验证的重大催化；
- 首次回踩状态 CONFIRMED；
- 量能确认；
- 盈亏比不低于2:1；
- 当日涨幅不超过6%；
- 不处于封板状态；
- 没有高开、冲高回落、结构失效、数据不完整等硬风险。

正常环境试仓上限3%，退潮或冰点环境上限2%。Bark 必须显示：

```text
指令：可交易｜事件回踩试仓
```

未满足时显示：

```text
指令：不可交易｜强势观察不追高
```

## 9. 验证与发布门槛

任何执行阈值或 blocker 性质变更必须满足：

1. 不改变上游选股结果；
2. 补充单元测试和历史路径测试；
3. 使用点时数据，禁止未来数据泄漏；
4. 至少完成滚动训练/验证窗口；
5. 报告交易次数、期望收益、盈亏因子和最大回撤；
6. 评估滑点、涨跌停不可成交和同日止盈止损顺序；
7. 先影子运行，再考虑生产调整；
8. Bark 继续坚持双门禁，不允许模糊措辞替代可交易指令。
