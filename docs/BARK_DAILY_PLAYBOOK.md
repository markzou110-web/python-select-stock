# Bark Daily Playbook

## 盘中收到推送

- `可交易候选`：只在 14:40-14:55 做确认，价格贴近入场线、未破失效线、没有冲高回落长上影时，才允许小仓试买。
- `观察池`：不直接买。加入观察清单，等待回踩不破结构位、放量重新站稳，或次日再次被系统选出。
- `禁止追买/风险样本`：不买。只用于复盘，尤其回避高开、涨停、结构失效、陷阱风险高的票。
- `实盘持仓状态`：优先级高于新开仓。若提示跌破风控线或贴近风控线，先处理持仓，再考虑新票。

## 次日开盘

- 高开超过 3%：不追，等回踩。
- 接近涨停或一字高开：不追。
- 跌破止损线/结构失效线：取消买入计划。
- 平开或小幅高开且未破结构：继续等尾盘确认，不在早盘追单。

## 收盘后复盘

- 看复盘中心的 `交易桶表现`：优先保留 `TRADE` 胜率和均收益持续占优的策略。
- 看 `次日跟踪` 的 `执行动作`：统计哪些票因为高开不追、风控触发、冲高回落被过滤。
- 回测实验室使用 `次日开盘确认` 模式，避免把无法成交的信号当作真实利润。
